A small release. `manifest.json` changes its `Version` only; `Ziggfreed:RpgStations >=1.1.1`, `Ziggfreed:ZiggfreedCommon >=2.4.0` and `Ziggfreed:MMOSkillTree ^1.7.1` stay. The README names the build's output `MMOSkillStationsPack-1.1.3.zip`.

- **Fixed: The Greater Table's silk delivery.** `Server/ZiggfreedCommon/Quests/MMOSkillTree/Stations/Disenchanting/The_Greater_Table.json`'s `bring_silk` step turns in 12 `Ingredient_Spider_Silk` where it asked for 6 `Ingredient_Bolt_Silk`, which vanilla crafts only at `Loombench` (`Bench_Loom` is a `Developer` quality item on Update 7), matching RPG Stations 1.1.3's recipe. With this pack the quest is the only way to the Greater Disenchanting Table, so it could not be finished.
- **Changed: Orrin asks for the spider silk.** `dialogue.mmo_enchanter.greater_offer.text` names Spider Silk where it named Bolts of Silk, and `dialogue.mmo_enchanter.greater_brief.text` points at the cave spiders where it named the loom, in all nine locales.
