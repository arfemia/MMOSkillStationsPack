A small release. `manifest.json` changes its `Version` and its `Ziggfreed:ZiggfreedCommon` floor, from `>=2.3.0` to `>=2.4.0`; `Ziggfreed:RpgStations >=1.1.1` and `Ziggfreed:MMOSkillTree ^1.7.1` stay. No shipped id changes. The README names the build's output `MMOSkillStationsPack-1.1.2.zip`.

- **Changed: Marn's conversation gates on CommonLib's `Requires` condition.** `Server/ZiggfreedCommon/Dialogues/MMOSkillTree/Mmo_Sawyer.json`'s two `Gate` conditions, which MMO Skill Tree 1.7.2 hands to CommonLib and deprecates, are written as CommonLib 2.4.0's `{"Type": "Requires", "Requires": {...}}` with the same blocks, so the pack needs CommonLib 2.4.0. The README's Requires section and the store page say so.

- **Fixed: ru-RU names the Forgotten Temple as the game does.** In `Server/Languages/ru-RU/mmoskilltree.lang`, `dialogue.mmo_sawyer.first_words.text`, `dialogue.mmo_sawyer.yard_talk.text` and `dialogue.mmo_enchanter.first_words.text` write "Забытом храме" and "Забытого храма", the temple lower-case, where they wrote "Храме" and "Храма". No other locale changes.
