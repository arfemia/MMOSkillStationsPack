# Patch notes - MMO Skill Stations Pack

Per-version public release notes (newest first). Same paradigm as the main mod repo: YAML frontmatter (`version`/`type: patch-note`/`status`), user-facing voice, no em-dashes. `CURSEFORGE.md` is the store page; `README.md` is the repo description.

- [[0.1.0]] - held, releases with RPG Stations 0.1.0: first release, the Sawmill, plus Sawyer Marn in the Forgotten Temple with seven Sawmill quests (a daily among them), eighteen achievements under a Stations category and the Sawmiller's Crown flair. The Anvil plus the Smithing and Cooking skills are held back under `unreleased/`.
