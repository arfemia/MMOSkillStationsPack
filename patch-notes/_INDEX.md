# Patch notes - MMO Skill Stations Pack

Per-version public release notes (newest first). Same paradigm as the main mod repo: YAML frontmatter (`version`/`type: patch-note`/`status`), user-facing voice, no em-dashes. `CURSEFORGE.md` is the store page; `README.md` is the repo description.

- [[1.0.0]] - held, releases with RPG Stations 1.0.0 and MMO Skill Tree 1.6.1: first release, the Sawmill, plus Sawyer Marn in the Forgotten Temple with twelve quests (the Sawmill chain, the Marn's Edge line, the Standing Order daily and the Trim Work repeat among them), seven bounty contracts, twenty-six achievements under a Stations category, three hatchets, the woodcutter's kit and the Sawmiller's Crown flair. The Anvil plus the Smithing and Cooking skills are held back under `unreleased/`.
